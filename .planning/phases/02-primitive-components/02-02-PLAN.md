   - Import cva, VariantProps from class-variance-authority
   - Import cn from '@/lib/utils'
   - Define `badgeVariants` with cva():
     - Base: inline-flex items-center font-medium rounded-full ring-1 ring-inset ring-black/10
     - Variants for `variant`:
       - default: bg-gray-100 text-gray-700
       - primary: bg-primary-100 text-primary-800
       - success: bg-success-100 text-success-800

     - Variants for `size`:
       - sm: px-2 py-0.5 text-xs
       - md: px-2.5 py-1 text-sm
     - defaultVariants: { variant: 'default', size: 'md' }
   - Props: children (ReactNode), variant, size, className, icon (optional ReactNode)
   - Export BadgeVariants type

2. Create Avatar.tsx:
   - Props interface (AvatarProps):
     - src?: string (image URL)
     - alt?: string (for accessibility)
     - name?: string (for fallback initials)
     - size?: 'xs' | 'sm' | 'md' | 'lg' | 'xl'
     - className?: string
   - Size classes:
     - xs: w-6 h-6 text-xs
     - sm: w-8 h-8 text-sm
     - md: w-10 h-10 text-base
     - lg: w-12 h-12 text-lg
     - xl: w-16 h-16 text-xl
   - Logic:
     - If src provided and loads successfully, show img
     - Use onError to handle broken images
     - Fallback to initials from name (first letter of first + last word, uppercase)
     - If no name, show generic user icon from lucide-react (User icon)
   - Styling: rounded-full, overflow-hidden, bg-gray-100 for fallback, flex items-center justify-center
   - Use cn() for className composition

Create Icon.tsx as a thin wrapper around lucide-react icons for consistent sizing:

   - className?: string
   - Rest props via SVGAttributes<SVGElement> for aria-label, etc.
4. Size mapping (consistent with design system):
   - xs: w-3 h-3
   - sm: w-4 h-4
   - md: w-5 h-5
   - lg: w-6 h-6
   - xl: w-8 h-8
5. Render the icon component with size classes merged via cn()
6. Export Icon and IconProps

Usage example:
```tsx
import { Icon } from './Icon';
import { Settings } from 'lucide-react';

<Icon icon={Settings} size="md" className="text-gray-500" />
```

Note: This is intentionally a thin wrapper. It provides consistent sizing without adding complexity. Direct lucide-react usage is still valid for cases needing custom sizing.
