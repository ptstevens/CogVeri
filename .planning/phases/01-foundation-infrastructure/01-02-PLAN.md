  <action>
1. Install the Tailwind ESLint plugin:

```bash
cd frontend && npm install -D eslint-plugin-tailwindcss
```

2. Update `frontend/.eslintrc.json` to add Tailwind rules:

```json
{
  "root": true,
  "env": { "browser": true, "es2020": true },
  "extends": [
    "eslint:recommended",
    "plugin:@typescript-eslint/recommended",
    "plugin:react-hooks/recommended",
    "plugin:react/recommended",
    "plugin:tailwindcss/recommended"
  ],
  "ignorePatterns": ["dist", ".eslintrc.json", "node_modules"],
  "parser": "@typescript-eslint/parser",
  "parserOptions": {
    "ecmaVersion": "latest",
    "sourceType": "module",
    "project": "./tsconfig.json",
    "ecmaFeatures": {
      "jsx": true
    }
  },
  "plugins": ["react-refresh", "react", "@typescript-eslint", "tailwindcss"],
  "settings": {
    "react": {
      "version": "detect"
    },
    "tailwindcss": {
      "callees": ["cn", "clsx", "classnames", "cva"],
      "config": "./tailwind.config.js",
      "cssFiles": ["./src/**/*.css"],
      "removeDuplicates": true
    }
  },
  "rules": {
    "react-refresh/only-export-components": [
      "warn",
      { "allowConstantExport": true }
    ],
    "react/react-in-jsx-scope": "off",
    "react/prop-types": "off",
    "@typescript-eslint/no-unused-vars": [
      "error",
      {
        "argsIgnorePattern": "^_",
        "varsIgnorePattern": "^_"
      }
    ],
    "@typescript-eslint/explicit-module-boundary-types": "off",
    "@typescript-eslint/no-explicit-any": "warn",
    "no-console": ["warn", { "allow": ["warn", "error", "info"] }],

    "tailwindcss/classnames-order": "warn",
    "tailwindcss/enforces-negative-arbitrary-values": "warn",
    "tailwindcss/enforces-shorthand": "warn",
    "tailwindcss/no-arbitrary-value": "warn",
    "tailwindcss/no-custom-classname": "warn",
    "tailwindcss/no-contradicting-classname": "error"
  }
}
```

**Rule severity rationale:**
- `no-arbitrary-value`: "warn" initially (not "error") - allows legitimate calc() cases while flagging for review
- `no-custom-classname`: "warn" - catches non-Tailwind classes but allows component-specific selectors
- `no-contradicting-classname`: "error" - these are always bugs (e.g., `text-red-500 text-blue-500`)
- `classnames-order`: "warn" - consistency, not blocking

**Settings explanation:**
- `callees`: Functions that accept class names (cn, clsx, classnames, cva) - ESLint parses these too
- `config`: Points to Tailwind config so ESLint knows valid class names
- `cssFiles`: Where to look for custom CSS classes

- `npm ls eslint-plugin-tailwindcss --workspace=frontend` shows package installed
- `cat frontend/.eslintrc.json | grep tailwindcss` shows plugin is configured
- ESLint config has all 6 Tailwind rules defined
  </verify>
  <done>eslint-plugin-tailwindcss installed and configured with all rules</done>
</task>
