   - Import cva, VariantProps from class-variance-authority

  <name>Task 2: Set up Storybook with Vite and accessibility addon</name>
  <files>frontend/.storybook/main.ts, frontend/.storybook/preview.ts, frontend/package.json</files>
  <action>
Initialize Storybook for the frontend project:

1. Run Storybook init with Vite builder:
   ```bash
   cd frontend && npx storybook@latest init --builder @storybook/builder-vite --yes
   ```
   This creates .storybook folder and adds dependencies.

2. Install accessibility addon:
   ```bash
   cd frontend && npm install -D @storybook/addon-a11y
   ```

3. Update .storybook/main.ts:
   ```ts
   import type { StorybookConfig } from '@storybook/react-vite';

   const config: StorybookConfig = {
     stories: ['../src/**/*.stories.@(js|jsx|mjs|ts|tsx)'],
     addons: [
       '@storybook/addon-essentials',
       '@storybook/addon-a11y',
       '@storybook/addon-interactions',
     ],
     framework: {
       name: '@storybook/react-vite',
       options: {},
     },
     docs: {
       autodocs: 'tag',
     },
   };

   export default config;
   ```

4. Update .storybook/preview.ts to load Tailwind:
   ```ts
   import type { Preview } from '@storybook/react';
   import '../src/styles/index.css'; // Import Tailwind and design tokens

   const preview: Preview = {
     parameters: {
       controls: {
         matchers: {
           color: /(background|color)$/i,
           date: /Date$/i,
         },
       },
       a11y: {
         config: {
           rules: [
             { id: 'color-contrast', enabled: true },
             { id: 'label', enabled: true },
           ],
         },
       },
     },
   };

   export default preview;
   ```

5. Verify Storybook runs:
   ```bash
   cd frontend && npm run storybook -- --smoke-test
   ```
