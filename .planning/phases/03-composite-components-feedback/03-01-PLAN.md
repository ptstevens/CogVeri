   - Import `Toaster` and `useToasterStore` from react-hot-toast
   - ToastProvider MUST include the stacking limit logic internally:
     ```typescript
     export function ToastProvider() {
       const { toasts } = useToasterStore();
       const TOAST_LIMIT = 5;

       useEffect(() => {
         toasts
           .filter(t => t.visible)
           .filter((_, i) => i >= TOAST_LIMIT)
           .forEach(t => hotToast.dismiss(t.id));
       }, [toasts]);

       return <Toaster position="top-right" toastOptions={{ duration: 4000 }} />;
     }
     ```
   - This is a single component that renders Toaster AND manages the limit via useEffect
