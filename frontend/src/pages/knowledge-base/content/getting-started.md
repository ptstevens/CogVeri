# Welcome to CogVeri

CogVeri is an AI-powered platform that helps organizations create, manage, and evaluate task completions through video recordings and intelligent analysis.

## What is CogVeri?

CogVeri streamlines the process of verifying task completion by combining:

- **Video Recording** - Capture screen recordings of task execution
- **AI Analysis** - Automatically evaluate recordings against defined criteria
- **Structured Evaluation** - Use rubrics to ensure consistent, objective assessments
- **Review Workflows** - Enable managers to review and provide feedback

Whether you're training new employees, conducting assessments, or validating process compliance, CogVeri provides the tools to make verification efficient and reliable.

---

## Core Concepts

### Tasks

A **Task** is a specific piece of work assigned to a team member. Tasks are created from templates and include:

- Clear instructions for what needs to be done
- Duration expectations
- Evaluation criteria (via rubrics)
- A unique link for the assignee to submit their recording

### Templates

**Templates** are reusable task structures that define:

- The type of work being requested
- Detailed instructions for completion
- Minimum and maximum recording durations
- The evaluation rubric to use

Templates save time by allowing you to create standardized tasks quickly.

### Rubrics

**Rubrics** define the criteria used to evaluate task recordings. Each rubric contains:

- **Steps** - Individual criteria to check (e.g., "Opened the correct application")
- **Evidence Types** - Whether to look for speech, visual, or both types of evidence
- **Weights** - How important each step is to the overall score
- **Pass/Fail Requirements** - Which steps must be completed

### Recordings

**Recordings** are the video submissions captured by assignees. Each recording:

- Captures the screen and audio during task execution
- Is automatically transcribed for speech analysis
- Has keyframes extracted for visual analysis
- Is evaluated against the task's rubric

## Key Features

### AI-Powered Analysis

CogVeri uses Google's Gemini AI to analyze recordings:

- **Speech Analysis** - Detects keywords and phrases in the audio transcript
- **Visual Analysis** - Identifies UI elements, actions, and content in video frames
- **Smart Scoring** - Combines speech and visual evidence for accurate evaluation

### Flexible Evaluation

Create rubrics that match your specific needs:

- Define any number of evaluation steps
- Set custom keywords and visual criteria
- Weight steps by importance
- Mark steps as required or optional

### Real-Time Recording

The built-in recorder provides:

- Screen capture with optional audio
- Recording timer with duration limits
- Immediate upload on completion
- Support for re-recording if needed

## Quick Start Guide

### 1. Create a Template

Start by creating a template that defines your task structure:

1. Go to **Settings** > **Templates**
2. Click **Create Template**
3. Fill in the title, description, and instructions
4. Set duration limits
5. Save the template

### 2. Build a Rubric

Add evaluation criteria to your template:

1. Open your template
2. Click **Edit Rubric**
3. Add steps with clear descriptions
4. Set evidence types and weights
5. Save the rubric

### 3. Create and Assign a Task

Create a task from your template:

1. Go to **Tasks** > **Create Task**
2. Select your template
3. Fill in task details
4. Copy the task link
5. Send to the assignee

### 4. Review the Recording

After submission, review the results:

1. Open the task
2. View the AI analysis scores
3. Watch the recording
4. Provide feedback if needed
5. Mark as approved or request re-submission
