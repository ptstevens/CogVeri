1. Install @tanstack/react-table:
   ```bash
   cd frontend && npm install @tanstack/react-table
   ```

2. Create `frontend/src/components/ui/patterns/DataTable/DataTable.tsx`:
   - Generic component: `DataTable<TData>`
   - Props interface:
     ```typescript
     interface DataTableProps<TData> {
       columns: ColumnDef<TData>[];
       data: TData[];
       pageCount?: number;
       pagination?: PaginationState;
       onPaginationChange?: (pagination: PaginationState) => void;
       sorting?: SortingState;
       onSortingChange?: (sorting: SortingState) => void;
       isLoading?: boolean;
       emptyState?: React.ReactNode;
     }
     ```
   - Use `useReactTable` with:
     - `getCoreRowModel()` always
     - `manualPagination: true` when pageCount provided
     - `manualSorting: true` when onSortingChange provided
   - Table structure using semantic HTML: `<table>`, `<thead>`, `<tbody>`, `<th>`, `<td>`
   - Use `flexRender` for cell/header rendering
   - Loading state: Show Spinner component centered in tbody when isLoading=true
   - Empty state: Show emptyState prop or default "No results" message when data.length === 0 and not loading
   - Styling with design tokens:
     - Table: `w-full border-collapse`
     - Header: `bg-gray-50 border-b border-gray-200`
     - Header cells: `px-6 py-3 text-left text-xs font-medium text-gray-500 uppercase tracking-wider`
     - Body rows: `hover:bg-gray-50 border-b border-gray-100`
     - Body cells: `px-6 py-4 whitespace-nowrap text-sm text-gray-900`
   - IMPORTANT: Wrap entire table in `rounded-lg border border-gray-200 overflow-hidden` container

3. Create `frontend/src/components/ui/patterns/DataTable/DataTableColumnHeader.tsx`:
   - Props: `column: Column<TData>`, `title: string`
   - Render clickable header if column.getCanSort() is true
   - Sort indicators using lucide-react icons: ArrowUpDown (unsorted), ArrowUp (asc), ArrowDown (desc)
   - Click handler: `column.getToggleSortingHandler()`
   - Styling: `flex items-center gap-2 cursor-pointer select-none` when sortable

AVOID:
- Do NOT use Material-UI or any other UI library (bundle size - Pitfall 10)
- Do NOT create inline column definitions (causes infinite re-renders - Pitfall from research)
- Do NOT hardcode colors - use Tailwind classes that reference design tokens
