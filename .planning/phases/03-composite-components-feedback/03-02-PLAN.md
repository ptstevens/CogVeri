Create new Modal component using Radix Dialog primitives:

1. Create `frontend/src/components/ui/composites/Modal/Modal.tsx`:

Structure:
```typescript
import * as Dialog from '@radix-ui/react-dialog';
import { cva, type VariantProps } from 'class-variance-authority';
import { X } from 'lucide-react';
import { cn } from '@/lib/utils';
```

2. Define CVA variants for size:
```typescript
const modalVariants = cva(
  'fixed top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2 bg-white rounded-lg shadow-large w-full',
  {
    variants: {
      size: {
        sm: 'max-w-sm',
        md: 'max-w-lg',
        lg: 'max-w-2xl',
        xl: 'max-w-4xl',
      },
    },
    defaultVariants: {
      size: 'md',
    },
  }
);
```

3. Create main Modal component:
- Props: `open`, `onOpenChange`, `size`, `children`
- Render Dialog.Root with Dialog.Portal containing:
  - Dialog.Overlay (backdrop): `fixed inset-0 bg-black/50`
  - Dialog.Content with modalVariants

4. Create sub-components attached to Modal:
- `Modal.Header`: Wraps Dialog.Title, includes close button
- `Modal.Body`: Wraps Dialog.Description for main content
- `Modal.Footer`: Flex container for action buttons

5. Export pattern:
```typescript
export const Modal = Object.assign(ModalRoot, {
  Header: ModalHeader,
  Body: ModalBody,
  Footer: ModalFooter,
});
```

6. Create `frontend/src/components/ui/composites/Modal/index.ts`:
   - Export Modal and types

API compatibility notes:
- Old API: `<Modal isOpen={} onClose={} title="" size="">{children}</Modal>`
- New API: `<Modal open={} onOpenChange={} size=""><Modal.Header>title</Modal.Header><Modal.Body>{content}</Modal.Body></Modal>`
- This is intentionally different - compound pattern is more flexible
- Old Modal.tsx will be deprecated but NOT deleted in this phase

Important:
- Use `Dialog.Close asChild` pattern for close button
- Preserve existing animations (modal enter scale effect)
- Add proper TypeScript types for all props
- Use design tokens for colors (no hardcoded values)
