  <files>
    frontend/src/components/ui/patterns/Navigation/Breadcrumbs.tsx

  <action>
1. Create directory: `mkdir -p frontend/src/components/ui/patterns/Navigation`

2. Create `frontend/src/components/ui/patterns/Navigation/Breadcrumbs.tsx`:

   Interface:
   ```typescript
   export interface BreadcrumbItem {
     label: string;
     href: string;
   }

   export interface BreadcrumbsProps {
     /** Custom items override auto-generation from path */
     items?: BreadcrumbItem[];
     /** Home path for first breadcrumb (default: '/dashboard') */
     homePath?: string;
     /** Home label (default: uses Home icon) */
     homeLabel?: string;
     /** Show home icon or text (default: true = icon) */
     showHomeIcon?: boolean;
     /** Additional className */
     className?: string;
   }
   ```

3. Implementation:
   - Use `useLocation()` from react-router-dom to get current pathname
   - If `items` prop provided, use those directly
   - Otherwise, auto-generate from pathname:
     ```typescript
     const pathnames = location.pathname.split('/').filter(x => x);
     const breadcrumbs = pathnames.map((segment, index) => ({
       label: formatSegment(segment), // 'task-details' -> 'Task Details'
       href: '/' + pathnames.slice(0, index + 1).join('/'),
     }));
     ```
   - `formatSegment` helper: Replace hyphens with spaces, capitalize each word, handle UUID segments (show as "Details" or truncate to 8 chars)

4. WAI-ARIA compliance (CRITICAL):
   - Wrap in `<nav aria-label="Breadcrumb">` (NOT aria-labelledby, just aria-label)
   - Use `<ol>` for the list (ordered hierarchy)
   - Use `<li>` for each item
   - Last item: `<span aria-current="page">` (NOT a link)
   - All other items: `<Link to={href}>` from react-router-dom

5. Styling:
   - Container: `flex items-center text-sm`
   - List: `flex items-center space-x-2`
   - Home icon: Use `Home` from lucide-react, `w-4 h-4`
   - Separator: `ChevronRight` from lucide-react, `w-4 h-4 text-gray-400 mx-1`
   - Links: `text-gray-500 hover:text-primary-600 transition`
   - Current page: `text-gray-900 font-medium`

6. Edge cases:
   - Empty pathname or just "/" -> show only Home
   - Very long labels -> truncate with `truncate max-w-[150px]` and title attr
   - UUID segments (36 char with dashes) -> show as "Details" or first 8 chars

AVOID:
- Do NOT use `<div>` instead of `<nav>` and `<ol>` (accessibility violation)
- Do NOT make the last item a link (confusing UX, it's the current page)
- Do NOT hardcode colors - use Tailwind classes with design tokens
- Do NOT use heroicons (use lucide-react per Pitfall 8 - single icon library)
